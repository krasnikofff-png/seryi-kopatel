# Исходники «Серого копателя»

Игра собирается в **один HTML-файл** из этой папки. Править нужно здесь, а не в собранном файле.

## Сборка

```
python3 build.py              # → dist/kopatel-v-pole.html (то, что публикуется)
python3 build.py --friends    # → index.html для ссылки друзьям (GitHub Pages)
```

## Что где лежит

| Папка / файл | Что внутри |
|---|---|
| `head.html`, `body.html`, `boot.js`, `tail.html` | разметка страницы и загрузочный скрипт |
| `css/` | оформление по разделам (гараж, находки, карты, комикс, нижняя панель…) |
| `js/` | код игры по разделам; порядок склейки — в `order.json` |
| `art/` | все картинки: находки (`find-img/`), детекторы, лопаты, транспорт, карты, блокнот |
| `friends/` | обёртка «включите JavaScript» для версии друзьям |

Главные разделы кода:
- `js/02-dannye-igry.js` — каталог находок и классы;
- `js/14-ekonomika-…` — **таблица цен ECON** (все цены находок настраиваются здесь), создание поездки и вещей;
- `js/16-sobytiya-v-doroge.js`, `js/17-moral-v-pole.js` — события и моральные ситуации;
- `js/18-detektor.js`, `js/20-dejstviya-v-pole.js` — детектор, ВДИ, копание;
- `js/29…34` — гараж: находки, альбом, снаряжение, долг, чистка;
- `js/24…28` — сюжет и кадры комикса.

Картинки в коде пишутся как `@art(find-img/pyatak-1811.png)` — при сборке они встраиваются в файл.

## Проверки (`tests/`)

- `node tests/parse_chunks.js` — каждый раздел кода читается без ошибок;
- `node tests/ast_eq.js A.html B.html` — смысл программы в двух сборках одинаковый (для чистых переформатирований);
- `node tests/styles.js` + `python3 tests/styles_cmp.py` — вычисленные стили всех элементов не изменились;
- `node tests/regress.js` + `python3 tests/compare.py` — скриншоты ключевых экранов и итоговое сохранение.
